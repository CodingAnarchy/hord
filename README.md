# Hord

A transactional database over a semantic code graph. Spec: [`docs/spec.md`](docs/spec.md).

This repository is set up for Grok Build (inside Herdr). Project skills live in `.grok/skills/`.

## Start

From a Herdr pane whose cwd is this repo:

```bash
grok
```

Then:

- `/hord M0` — implement the current milestone
- `/hord-herdr M0` — fan the milestone out across Grok panes in Herdr
- `/hord-adr <open-question>` — write an ADR before choosing an OPEN spec item
